# Home — Дом

Первый экран после login. Главные виджеты, ощущение «прихожей с тёплым светом».

**Ambient hue:** `#FFC9A8` тёплое янтарное свечение
**Effects:** floating particles, мягкий vignette по краям

## Виджет 1: Header (приветствие)

### Spec

- **Padding:** 24px 20px (mobile), 32px 32px (desktop)
- **Background:** transparent (НЕ в карточке)
- **Layout:**
    - **Аватары parallel** (left): два blob-аватара 48px, gap 12px
    - **Right:**
        - Title: «Доброе утро, [имя]» / «Добрый день, [имя]» / «Тёплый вечер, [имя]» / «Доброй ночи, [имя]»
            - Fraunces text-2xl (32px) на mobile, text-3xl (48px) на desktop
            - `ink.primary`
            - Weight 500
        - Subtitle (text-sm `ink.secondary`): «Вы знаете друг друга 142 дня · 84 дня вместе»

### Динамическое приветствие (по времени)

| Время | Текст |
|-------|-------|
| 5-11 | «Доброе утро, [имя]» |
| 11-17 | «Добрый день, [имя]» |
| 17-22 | «Тёплый вечер, [имя]» |
| 22-5 | «Доброй ночи, [имя]» |

## Виджет 2: Mood Pair-Glance

Самый важный виджет — двух blob'а вашего настроения.

### Spec

- **Container:** Card hero variant, radius-xl (32px), padding 32px
- **Min-height:** 240px (mobile), 280px (desktop)
- **Background:** glass + extra inner radial gradient `glow.soft` alpha 0.05 в центре

### Layout

- Mobile: blob'ы вертикально или диагонально, чтобы создать ощущение «расположения в комнате»
- Desktop: blob'ы рядом по центру, gap 100px

### Каждый blob

- **Size:** 96px mobile, 140px desktop
- **Shape:** organic morphing — см. [02-components.md → Blob](../02-components.md#blob-универсальный-morphing-blob)
- **Color:** personal hue + влияние эмоции
- **Glow halo:** soft outer

### Под каждым blob'ом

- Имя (text-base, weight 500)
- Vibe-tag (text-sm `ink.secondary`) — если разрешено видеть
- «тёплая» / «спокойная» / «насыщенная» — слово соответствует уровню энергии × эмоции

### Между blob'ами

- Если оба чекнулись сегодня — **тонкая нить света** (1px line, тёплый gradient, slight glow)
- Если только один — нити нет
- Нить может слегка пульсировать

### CTA-state (если ты не чекался)

- Твой blob полупрозрачный (opacity 0.5)
- Под ним вместо vibe-tag — кнопка-ghost «как ты?» (text-sm, `glow.warm` color)
- Tap → переход в Mood-комнату

### Tap-actions

- Tap на свой blob → переход в Mood-комнату на check-in
- Tap на blob партнёра → small popover с тем что она разрешила видеть (если ничего — «Кристина ещё не отметилась сегодня»)

## Виджет 3: Next Plan

Ближайшее событие из календаря.

### Spec

- **Container:** Card default, radius-lg, padding 20px
- **Layout:**
    - **Left:** category dot (10px) + дата (text-sm uppercase, ink.muted)
    - **Center:** title (text-xl Fraunces) + где (text-sm `ink.secondary`)
    - **Right:** время (text-base, `ink.primary`)
    - Под title: «ты предложил» / «она предложила» (text-xs, `ink.muted`)

### Состояния

- **Если есть план:** карточка как выше
- **Если нет ближайших планов:** карточка с тёплым текстом «Тишина. Может, придумаем что-то?»
    - Текст центрирован
    - Под ним маленькая ghost-кнопка «открыть календарь»
- **Если план уже сегодня:** карточка subtle highlighted — warm border accent

## Виджет 4: Memory of the Day

Тёплое воспоминание из прошлого.

### Spec

- **Container:** Card hero variant, radius-xl
- **Padding:** 0 (фото в полную ширину), text padding 20px

### Layout

- **Top:** фото 16:9 ratio (на mobile full-width, на desktop max-width 600px)
    - Радиус сверху наследует контейнер, снизу прямой
    - Фон когда фото грузится — gradient `bg.surface-1` → `bg.surface-2`
- **Bottom (text section):**
    - Дата (text-xs uppercase `ink.muted`, например «28 ЯНВАРЯ 2026»)
    - Title (text-2xl Fraunces) — заметка к моменту
    - Optional: mood-tag (chip с тёплыми/тёмными словами как «волшебно», «тепло», «волнующе»)

### States

- **Если нет фото за сегодня:** карточка показывает случайный момент из истории или скрывается (не рендерится)
- **Tap:** разворачивается полноэкранно с lens-blur (см. [04-motion.md](../04-motion.md))

## Виджет 5: Wishlist Peek

Хотелки партнёра + общие.

### Spec

- **Container:** subtle card или просто секция без background
- **Title строка:** «Кристине сейчас хочется...» (text-sm `ink.secondary`)
- **Grid:** горизонтальный scroll-row на mobile; 4 colon grid на desktop

### Cards внутри

- WishCard в **compact** mode (см. [02-components.md → WishCard](../02-components.md#wishcard))
- Размер: 120×160px (mobile), 160×200px (desktop)
- 2 случайные из «Хочу» партнёра + 1 из «Наше» (можно перемешать)
- Showing: image (top 100×100), title (text-sm 1 line clamp), category dot

### Tap

- Tap на card → переход в Wishlist на конкретный item
- Tap на title-строку «Кристине сейчас хочется» → переход в её Wishlist

## Time-aware shuffling

Виджеты переупорядочиваются по времени дня.

| Время | Порядок (top → bottom) |
|-------|------------------------|
| **Утро 5-11** | Header → **Mood Pair** (с прим. «как ты?») → Next Plan → Memory → Wishlist |
| **День 11-17** | Header → Next Plan → Mood Pair → Wishlist → Memory |
| **Вечер 17-22** | Header → Memory → Mood Pair (с итогом дня) → Next Plan → Wishlist |
| **Ночь 22-5** | Header («доброй ночи») → Memory → Mood Pair → Next Plan → Wishlist |

В макетах нарисовать **2 версии** Дома — утреннюю и вечернюю — чтобы было понятно как переупорядочивание выглядит.

## Empty / first-time

### Все 5 виджетов пустые (первый день)

- Header работает как обычно
- Mood Pair: 2 sleeping blob'a, оба с CTA «отметь настроение»
- Next Plan: «Календарь пока пустой. Добавим первый план?»
- Memory of the day: скрыт (или показывает welcome-blurb типа «совсем скоро тут появятся ваши моменты»)
- Wishlist: «Список желаний ждёт. Что хотелось бы?»

## Anti-pattern

- ❌ Никаких «уведомлений» сверху виджетов («У тебя 3 новых события!»)
- ❌ Никаких CTA «Premium», «Pro», «Upgrade»
- ❌ Никаких banner'ов, tutorial overlay'ев
- ❌ Лишних inputs на главной (search bar и т.п.)
