# 01 — Концепция

## Что такое us

**us** — это цифровой дом для двоих. Не «приложение для пар», не productivity-инструмент, не социальная сеть. Это место в интернете, которое существует только для нас и ощущается как наша общая комната.

Открываешь — и сразу чувствуешь тёплый свет, тишину, late-night vibe, ощущение, что это место ждало именно тебя.

## Для кого

Этот проект сделан **для конкретных двоих людей** — без бизнес-цели, без масштабирования на других пар, без план B превращения в продукт. Это делает решения проще и интимнее:

- регистрации нет — два аккаунта создаются вручную через Supabase admin
- онбординг минимальный — просто залогинились и оказались дома
- хардкод имён, дат, любых констант — приемлем
- никаких generic-абстракций «User profile / Couple entity» сверх необходимого

## Контекст

- Живём в одном городе, но физически — раздельно
- Через ~6 месяцев планируем съехаться
- Видимся часто, но не каждый день
- Оба не пользуемся синхронными созвонами — общение текстом

## Ядерные принципы

### 1. Async by design

- Никаких «онлайн / офлайн» индикаторов
- Никаких read-receipts
- Никаких «печатает...»
- Никаких presence-маркеров
- Партнёр видит то, что ты оставил, тогда, когда сам откроет

Это убирает целый класс тревожности («он онлайн, но не пишет», «давно был в сети») и упрощает архитектуру (никакого realtime в MVP).

### 2. Granular intimacy

Близость должна **выбираться**, а не навязываться приложением.

- Каждое поле в mood-чек-ине имеет три уровня видимости (полностью / vibe-only / скрыто)
- Дефолты — мягкие; контроль — точный
- Партнёр никогда не видит то, что ты не разрешил
- Подробно: [docs/04-privacy-and-notifications.md](./04-privacy-and-notifications.md)

### 3. No streaks, no FOMO

Приложение никогда не давит.

- Никаких streak'ов, которые ломаются при пропуске
- Никаких progress bar'ов «вы стали меньше общаться»
- Никаких «вы потеряете прогресс!»
- Ачивки появляются как тихие подарки, никогда не как награды за послушание

## Метафора: дом с комнатами

us устроен как дом. Каждая «комната» — отдельная функция со своей атмосферой (цвет, фон, анимация). Между комнатами переходишь через таб-бар на мобиле / sidebar на десктопе.

Все комнаты живут под одной крышей — общая типографика, общий ритм анимаций, общий вайб приватности. Но каждая чуть разная — лиловое лунное «Настроение», тёплая бумажная атмосфера «Календаря», розовый pinboard «Хотелок», ночное небо «Профиля».

Цель — чтобы переход между комнатами ощущался как «вошёл в другую комнату дома», а не «переключил вкладку приложения».

## Что НЕ будет

- Звонков, sleep-calls, голосовых синхронных активностей
- Streak-механик любого рода
- Чужих людей — никаких friends, social, sharing наружу
- Корпоративных шаблонов: `task`, `assignee`, `due date` в стиле todo-приложений
- Эмодзи в категориях (используем цветовые метки)
- Realtime presence / online-индикаторов
- Surprise-механики подарков (рассматривали, отвергли как ненужное)
- Полноценного Memory Vault как отдельной комнаты (схлопнули в виджет на Доме)
- Web push notifications в MVP (только in-app badge)
- Multi-language (только RU)

## Ключевые решения, принятые при брейншторминге

| Решение | Альтернатива | Почему так |
|---------|--------------|-----------|
| Только для нас двоих | Продукт для пар | Личный проект, не SaaS |
| Mobile-first PWA | Native / desktop-first | Чаще открывают с телефона |
| Полностью async | Soft presence + pings | Меньше тревоги, проще архитектура |
| Granular privacy per field | Auto-share всё / opt-in share всего | Уважение к нюансам |
| Vercel + Supabase | Self-hosted | Быстрее, проще, free tier подходит |
| Memory of the day виджет | Полноценный архив | Минимум входа, максимум ностальгии |
| Cute achievements, no streaks | Полноценная геймификация | App никогда не наказывает |
| Dark-only в MVP | Сразу light + dark | Late-night vibe — главная вибрация |
| Гендер как визуальный слой | Без различий / функциональные различия | Personal hue + cycle-tracking (v0.2) |
| 4 комнаты + Профиль | 6 комнат | Меньше навигации |
| Bottom-nav без подписей | С подписями | Чище визуально |
