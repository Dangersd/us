# 04 — Приватность и уведомления

Сводный документ по всем приватность-механикам и поведению уведомлений.

## Базовая модель

В us два уровня данных:

1. **Личные** — видны только владельцу (mood-чек-ин, cycle-данные, personal settings)
2. **Общие** — видны обоим (события календаря, wishlist «Наше», общие даты, ачивки уровня пары)

Гибрид — **shared с гранулярными уровнями** — используется в mood-системе и cycle-индикаторе.

## Mood visibility (per-field, per-day)

Под каждым полем mood-чек-ина — мини-индикатор того, что видит партнёр:

- 👁 **Видно полностью** — точное значение (например: «энергия 73%»)
- 🌫 **Видно как vibe** — округлено до «тёплый / спокойный / насыщенный», без точности
- 🌑 **Скрыто** — партнёр видит только что ты чекался, не *что* отметил

Кликаешь — переключаешь. Дефолты задаёшь один раз в Профиле, тут только override на конкретное поле в конкретный день.

### Mood visibility defaults

| Поле | Дефолт |
|------|--------|
| Энергия | 🌫 vibe |
| Стресс | 🌫 vibe |
| Social battery | 👁 полностью (самое практичное — «не лезь сейчас» / «приходи») |
| Эмоция | 👁 полностью |
| Цикл (период, v0.2) | 🌑 скрыто (только ambient phase, если она разрешила) |
| Симптомы (v0.2) | 🌑 скрыто |

## Cycle privacy (v0.2)

Цикл — самые чувствительные данные в приложении.

**На её стороне:**
- Все cycle-данные (даты, симптомы, статистика) — приватные, видны только ей
- Раздел «Цикл» в Профиле существует только в её аккаунте
- Mood-чек-ин получает доп. поля (период, симптомы) — приватные по умолчанию

**На его стороне:**
- Может видеть только **ambient phase-индикатор** в её mood blob'е — лёгкая луна-фаза (новолуние / растущая / полнолуние / убывающая)
- Никаких слов «период», «PMS», «овуляция»
- Только фаза-метафора, без интерпретации
- Она может выключить shared-индикатор → у него blob без фазы

**RLS-уровень:**
- Cycle-таблицы доступны только её UID
- Партнёр получает phase-индикатор через серверный compute (Postgres function или Route Handler), который выдаёт **только** перевод дня цикла в фазу-метафору, без сырых данных

## Shared гибрид — wishlist

- «Я хочу» и «Я люблю» каждого видит партнёр (по умолчанию полностью)
- «Наше» видят и редактируют оба
- Surprise-механика отсутствует (рассматривали, отвергли)

## Calendar privacy

- Все события видны обоим (по дизайну — это **наш** ежедневник)
- Cycle overlay в её календаре — только для неё (v0.2)
- Заметки/фото в событиях видны обоим
- Кто предложил — отображается обоим

## Профиль и общие даты

- Все общие даты — видны и редактируются обоими
- Ачивки коллекции — видны обоим (это «наша» коллекция)
- Личные настройки (тема, mood-defaults, уведомления) — только свои
- Cycle-настройки (v0.2) — только её

## Уведомления

### MVP — только in-app

В MVP **никаких web push notifications**. Уведомления = badge на иконке Bottom-nav комнаты, где что-то новое + список «накопилось» при заходе в комнату.

Пример: партнёр добавил план → у тебя при следующем заходе badge на иконке Календаря → в Календаре сверху строка «Партнёр добавил план в субботу».

### Toggle'ы (per-user, в Профиле)

| Событие | Дефолт | Описание |
|---------|--------|----------|
| Календарь — напоминания о событиях | ON | За 1 час до события (per-event override) |
| Календарь — партнёр добавил/обновил план | ON | |
| Mood — партнёр чекнулся | ON | Badge в Доме / Mood |
| Mood — партнёр не чекался N дней | OFF | Анти-FOMO. Если хочешь — включаешь сам. |
| Wishlist — партнёр добавил | ON | |
| Memory — «этот день в прошлом» | ON | Если за сегодня есть отмеченный момент в прошлом |

Глобальный mute switch — «не беспокоить никак, проверю сам».

### Anti-pattern

- ❌ Никаких уведомлений в стиле «вы давно не виделись»
- ❌ Никаких напоминаний типа «не забудьте отметить настроение»
- ❌ Никаких «партнёр расстроен — поговори с ней»
- ❌ Никаких уведомлений со словом «период» / «PMS» — никогда, нигде
- ❌ Никаких ачивок-уведомлений в системе (только in-app тихий toast)

## Web push (post-MVP)

Когда добавим (если):
- Только для критических событий (напоминание о свидании за час)
- Quiet hours (диапазон, когда пуши приглушены)
- Per-user opt-in (отдельная permission в браузере)
- Никаких пушей про cycle или mood

## Login / Account

- Регистрации нет
- Два аккаунта создаются вручную через Supabase admin с email-алиасами (`him@us.local` / `her@us.local`)
- Login-экран показывает две кнопки **«Я»** / **«Она»** — клик автозаполняет email-алиас, остаётся ввести только пароль
- Email пользователю нигде в UI не светится (нужен только под капотом для Supabase Auth)
- Пароли запоминает браузер → следующий вход = один клик
- Сменить пароль — можно
- Logout — можно
- Delete account — не нужно
