# Комната «Дом»

Сердце приложения. Открываешь приложение — попадаешь сюда. Это не дашборд из productivity-apps, это прихожая с тёплым светом, где сразу видно состояние «нас».

**Ambient hue:** `#FFC9A8` тёплое янтарное свечение
**Эффекты:** floating particles (пылинки в свете), мягкий vignette по краям

## Структура (мобильный вертикальный flow)

```
┌──────────────────────────────────┐
│  Аватары + приветствие           │  ← Шапка
├──────────────────────────────────┤
│                                  │
│   Mood Pair-Glance               │  ← 2 blob'а вместе
│   ваш + партнёра                 │
│                                  │
├──────────────────────────────────┤
│   Ближайший план                 │  
│   Пятница — кафе «Утро»          │
├──────────────────────────────────┤
│   Memory of the day              │  ← фото/момент из прошлого
│   28 января — первая прогулка    │
├──────────────────────────────────┤
│   Wishlist peek                  │  ← 2 случайных «хотелки»
│   [ свеча ] [ кухня мечты ]      │
└──────────────────────────────────┘
```

На десктопе те же виджеты, но раскладка 2-3 колоночная: Memory of the day крупно слева, mood/next-plan справа, wishlist снизу. Точную сетку детально проработаем в макетах.

## Виджеты подробно

### 1. Шапка с приветствием

- Два круглых аватара (легкое glow), между ними соединительный элемент (тёплая искра/линия)
- Текст: «Доброе утро, [имя]» / «Вечер, [имя]» — динамически по времени дня
- Под ним мелким: «Вы знаете друг друга 142 дня»
- Аватары — это входные точки в свой/чужой профиль

### 2. Mood Pair-Glance ⭐

Главный виджет Дома.

- Два blob'а рядом — твой и партнёра, мягко морфятся
- Цвет/форма зависит от настроения (см. [mood.md](./mood.md))
- Если ты не чекался сегодня — твой blob полупрозрачный, рядом мягкая CTA «как ты?»
- Если партнёр чекался — видишь то, что он разрешил видеть (granular privacy)
- Если партнёр не чекался — blob слегка «спит» (с лёгкой анимацией дыхания)
- Tap → переходит в комнату «Настроение»

В **v0.2** на стороне партнёра в её blob'е добавится ambient phase-индикатор (если она разрешила).

### 3. Ближайший план

- Из календаря — следующее событие
- Цветовая точка категории (без эмодзи)
- Дата + название
- Если планов нет — мягкое «Тишина. Может, придумаем что-то?» с tap'ом в Календарь

### 4. Memory of the day

- Фото/момент с этой даты в любом прошлом году/месяце
- Подпись: дата + короткая заметка, которая была привязана к фото
- Tap → разворачивается полноэкранно с lens-blur эффектом
- Если за эту дату ничего нет — показывает случайный момент или скрывается (не «No memories»)

**Источник данных:** прошедшие события в Календаре, к которым прикреплены фото + заметка (см. [calendar.md](./calendar.md) → «Прошедшие события → Memory of the day»).

### 5. Wishlist peek

- 2 случайные карточки из «Хочу» партнёра + 1 из «Наше»
- Tap → переход в комнату Хотелки

## Time-aware shuffling

Виджеты слегка переупорядочиваются по времени дня. Не радикально — swap 1-2 виджетов. Не должно дезориентировать.

| Время | Поведение |
|-------|-----------|
| **Утро (5-11)** | Mood-glance первым (плюс мягкий промпт «как ты?»), потом next plan, потом memory |
| **День (11-18)** | Next plan ближе к топу |
| **Вечер (18-23)** | Memory of the day поднимается, mood-glance показывает «итог дня» |
| **Ночь (23-5)** | Всё тише, фон темнее, animations slow down, на топе короткое «Спокойной ночи» |

## Empty / first-time states

- **Только зарегистрировались** — Дом показывает короткий warm-onboarding (3 шага: сделай первый mood / добавь первый план / поставь общие даты в профиле). Не маркетинговый, по-домашнему.
- **Партнёр ещё не присоединился** — видишь свою половину + мягкое «Пока тут только ты» (для нашего случая не актуально — аккаунты создаются обоим сразу вручную).

## Что НЕ на Доме

- Полная статистика → в Профиле
- Полный календарь → в Календаре
- Список ачивок → в Профиле
- AI-чат (когда появится) → отдельный layer, не виджет на Доме

## v0.2 / future
