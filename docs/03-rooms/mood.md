# Комната «Настроение»

Самая «характерная» комната. Здесь живёт центральная эмоциональная механика приложения.

**Ambient hue:** `#E8B4FF` лиловое лунное
**Эффекты:** анимированные blobs, gradient mesh, мягко пульсирующие; ощущение тихой ночи

## Daily Check-in

Сердце комнаты. Раз в день (если хочешь — чаще, можно реже, без давления).

### 4 базовых поля у обоих (MVP)

| Поле | Что измеряем | UI |
|------|--------------|----|
| **Энергия** | Сколько сил сегодня | Вертикальный «термометр» — мягкий градиент от тусклого синего к яркому янтарю |
| **Стресс** | Уровень напряжения | Слайдер «расслабленность ↔ натянутая струна», физически натягивается при увеличении |
| **Social battery** | Хочу ли я общения / уединения | Радиальный «аккумулятор», заполняется / опустошается |
| **Эмоция** | Доминанта дня | Выбор из 8-12 мягких эмодзи-blobs (кастомные кругляшки, не Apple-эмодзи) |

### Контролы

- Слайдеры — **не цифры 1-10**, а тактильные градиенты. Видишь *ощущение*, а не число. Скрытое значение 0-100 — для базы и для статистики.
- Свайп = подтверждение. Никаких «save» кнопок.
- Если день уже отмечен — всегда виден «обновить». История правок сохраняется тихо.

### v0.2 — Cycle-поля (только её аккаунт)

| Поле | Что измеряем |
|------|--------------|
| **Период** | Идёт ли цикл сегодня + интенсивность (лёгкий / средний / обильный) |
| **Симптомы** | Тэги: спазмы, головная боль, тошнота, грудь, либидо, сон, и т.д. |

## Per-field privacy controls

Под каждым полем мини-индикатор того, **что видит партнёр**:

- 👁 `видно полностью` — точное значение
- 🌫 `видно как vibe` — тёплый / спокойный / насыщенный, без точности
- 🌑 `скрыто` — партнёр видит только что ты чекался, не *что* отметил

Кликаешь — переключаешь. Дефолты задаёшь один раз в Профиле, тут только override на конкретное поле в конкретный день.

Дефолты — см. [04-privacy-and-notifications.md](../04-privacy-and-notifications.md#mood-visibility-defaults).

## Mood Blobs

Главный визуальный язык комнаты.

**Каждый человек = blob.** Не аватар-фото, а живая клякса, которая:

- **Цвет** — базируется на personal hue + смещается от эмоции (грусть → синева, радость → янтарь, спокойствие → лиловый)
- **Форма** — круглая в спокойствии, искривлённая в стрессе, опавшая при низкой энергии, «надутая» при высокой социальной батарее
- **Анимация** — дыхание (slow morphing) с частотой, связанной с энергией: низкая = медленные глубокие вдохи, высокая = живее
- **Aura** — свечение вокруг сильнее при высоких показателях

Два blob'а — твой и её — лежат в комнате рядом. Не сцеплены, но в одном пространстве. Когда оба отметились сегодня, между ними появляется лёгкая «нить света» (очень тонкая, тёплая).

**Tap на blob'е партнёра:**
- Раскрывается **только то, что она разрешила видеть** на сегодня
- Не история, не статистика — *сейчас*

## Cycle layer (v0.2, её аккаунт)

В её комнате «Настроение» появляется дополнительный нижний слой:

- **Фаза цикла как фон** комнаты — едва уловимое влияние на ambient hue (не агрессивное)
- **«Возможный день»-индикатор** — приватный, виден только ей: «возможно PMS», «возможно овуляция», без давления
- **Виджет цикла** — кружок с днями, фазами, симптомами за период
- **Полный календарь цикла + история** — отдельный экран внутри Профиля

На стороне партнёра (его аккаунт):
- В его Mood-комнате видит её blob с **ambient phase**-индикатором — лёгкая луна-фаза рядом с blob'ом (новолуние / полнолуние и т.п.)
- Никаких слов «период», «PMS», «овуляция». Только фаза-метафора.
- Она может в любой момент выключить shared-индикатор (тогда у него blob без фазы).

## History view

Под check-in'ом — **mini-pattern** последних 7 дней:

- Горизонтальный ряд из 7 мини-blobs (твоих) и под ним 7 мини-blobs (её, в рамках разрешённой видимости)
- Tap на день → раскрывается, что было отмечено

**Полная история** — отдельный экран «Mood History» (доступ через ⋯ в комнате): календарная сетка месяца с моодом каждого дня, можно листать назад. В v0.2 — опционально overlay цикла.

## Что НЕ в комнате

- Цели / задачи по mood («хочу больше энергии»)
- Сравнение с партнёром в стиле «у неё больше энергии, чем у тебя»
- Графики «вы стали хуже спать»
- Push'и «ты не чекался 3 дня»
