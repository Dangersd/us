# Профиль (Stats + Settings)

Заходишь через аватар сверху-справа. Объединяет статистику, ачивки, общие даты, цикл (v0.2, для её аккаунта), уведомления, тему, аккаунт.

**Ambient hue:** `#A8C9FF` ночное небо
**Эффекты:** звёздное поле как фон stats, ачивки как созвездия

## Шапка профиля

- Большой аватар-blob с personal hue (glow тебе соответствует)
- Рядом аватар партнёра (поменьше, glow её/его)
- Между — тонкая нить света
- Ник + дата знакомства / годовщины (например: «150 дней знакомы · 84 дня вместе»)

## Мы в цифрах (Stats)

Поэтичная статистика, не KPI-дашборд. Числа крупно, тёплым serif'ом (Fraunces).

| Карточка | Что показывает |
|----------|----------------|
| **Дни** | Дней знакомы / Дней вместе. Два больших числа рядом. |
| **Места** | Топ-3 локации из календаря (где чаще встречались). Без карты, только названия. |
| **Жанры** | Топ-3 категории событий (свидания / ужины / кино / поездки). |
| **Настроения** | Самая частая эмоция за последние 30 дней. У каждого своя. |
| **Желания** | Любимая категория wishlist'a (одежда, опыт, дом...) |
| **Воспоминания** | Сколько отмеченных моментов в Memory of the day на сегодня |

Никаких «activity score», никаких графиков «вы стали меньше общаться». Только тёплая инвентаризация.

## Ачивки (тихая коллекция)

Появляются как **«звёзды в созвездии»** — визуально это grid из ~30-50 потенциальных ачивок, где разлоченные горят тепло, остальные едва видны. По мере получения созвездие проявляется.

**Когда появляется новая:** тихий soft-toast снизу с тёплым свечением, на 4 секунды, потом исчезает. **Никаких confetti, никаких полноэкранных модалок.** Не пушится в системные уведомления.

### Примерный список (финальный — в спецификации)

- *Первая луна* — первый mood check-in
- *Параллель* — оба чекнулись в один день
- *Сто дней знакомства*
- *Год вместе*
- *Первый план* — первое событие в календаре
- *Странники* — посетили 5 разных мест
- *Хранитель* — 30 отмеченных моментов в Memory of the day
- *Алхимик* — 50 items в общем wishlist'е
- *Полнолуние* — 30 mood check-in'ов
- *Параллельные настроения* — 7 дней одинаковая эмоция у обоих
- *Восход* — первый совместный план на утро
- *Двенадцать лун* — её 12 циклов отслежено (v0.2, приватно)

Названия — atmospheric, не gamified.

## Общие даты

Видно обоим, редактируют оба. Эти даты автоматически становятся годовыми событиями в Календаре с пометками «N год вместе» / «возраст».

- Дата знакомства (когда начали общаться)
- Дата начала отношений
- День рождения её
- День рождения его
- (Опционально) первое свидание, первый поцелуй — больше нежных меток

## Цикл (только для её аккаунта, v0.2)

Полный раздел трекера — заменяет Flo для неё.

**Что внутри:**
- Календарь цикла (свой mini-grid, отдельный от общего Календаря)
- Текущая фаза + день цикла
- Лог менструаций (даты, интенсивность)
- Лог симптомов (тэги: спазмы, головная боль, либидо, сон, ...)
- Предсказание следующего периода + овуляции (на основе средней длины цикла)
- Статистика циклов (средняя длина, регулярность)
- Toggle: «Показывать ему фазу как ambient-индикатор» (дефолт OFF — она включает сама)
- Никаких уведомлений типа «приближается период» в push'ах — только в приложении

В MVP — раздела «Цикл» нет. Появляется в v0.2 сразу после первого деплоя.

## Уведомления (per-user, кастомизируемо)

В MVP — только in-app badge при заходе.

Отдельные toggle'ы для:
- Календарь — напоминания о событиях (за N часов, кастомно per event)
- Mood — партнёр чекнулся
- Wishlist — партнёр добавил
- Календарь — партнёр обновил/добавил план
- Memory — «этот день в прошлом» (если есть)

Глобальный mute switch — «не беспокоить никак, проверю сам».

Полная модель — в [04-privacy-and-notifications.md](../04-privacy-and-notifications.md).

## Тема и внешний вид

- Dark (в MVP), light — пост-MVP
- Personal hue — 3 предустановки в рамках твоей роли (предложение, см. [07-open-questions.md](../07-open-questions.md))
- Floating particles on/off
- Grain on/off
- Анимации — auto / reduced / off (под `prefers-reduced-motion`)

## Аккаунт

- Сменить пароль
- Logout
- (Email не отображается — создан вручную через Supabase admin)

## Что НЕ в Профиле

- Без friend-list'ов, social-фич
- Без публичных профилей
- Без public sharing статистики наружу
- Без интеграций с другими приложениями (Spotify и т.п.)
