# Комната «Календарь»

Не Google Calendar. **Наш ежедневник**, в который мы записываем планы как в общую тетрадь.

**Ambient hue:** `#F4D08A` тёплая бумага / янтарь
**Эффекты:** слегка зернистый фон («warm paper»), даты с эффектом «вытесненной чернилами»

## Виды и навигация

**Дефолт (mobile):** Agenda — список ближайших событий, и сверху мини-полоска месяца с маркерами под датами.

```
┌──────────────────────────────────┐
│   май 2026                       │
│  M T W T F S S                   │
│  ·   • ·   ·   · • ·             │  ← мини-месяц с точками
├──────────────────────────────────┤
│   СЕГОДНЯ • 19 мая               │
│   ─ Тихий день                   │
├──────────────────────────────────┤
│   Пятница • 22 мая               │
│   ● Кафе «Утро», 19:00           │  ← цветной маркер категории
│   она предложила                 │
├──────────────────────────────────┤
│   Воскресенье • 24 мая           │
│   ● Кино «Перфект Дэйз»          │
├──────────────────────────────────┤
│   📌 ИДЕИ (без даты)             │
│   ─ Поехать в Зеленоградск       │
│   ─ Попробовать ramen в новом    │
└──────────────────────────────────┘
```

**Альтернативный вид:** Month — полная сетка месяца, события как цветные пунктирки под датами. Toggle в правом верхнем углу.

**Десктоп:** обе вьюшки бок о бок — слева агенда, справа большой month-grid.

## Структура события

| Поле | Описание |
|------|----------|
| **Название** | Свободный текст |
| **Когда** | Дата + опционально время + опционально длительность |
| **Где** | Свободный текст или координата (без интеграции карт в MVP, просто строка) |
| **Категория** | См. ниже — цветная точка, без эмодзи |
| **Заметка** | Текстовое поле (markdown-light: переносы, *курсив*, **жирный**) |
| **Фото** | 0-3 фото (становятся кандидатами на Memory of the day после события) |
| **Напоминание** | За N часов/дней — кастомизируется per event |
| **Кто предложил** | Авто-определяется по тому, кто создал |
| **Состояние** | Запланировано / прошло / отменено (авто-меняется после даты) |

## Категории (цветами, без эмодзи)

| Категория | Цвет-метка | Поведение |
|-----------|------------|-----------|
| Свидание | Тёплый персик `#FFB4D1` | Стандарт |
| Ужин | Янтарь `#FFC9A8` | Стандарт |
| Кино / культура | Глубокий слива `#9B7EBD` | Стандарт |
| Поездка | Шалфей `#A8C5A0` | Стандарт |
| Годовщина | Золото `#E8C77B` | **Спец:** ежегодное повторение, показывает «N год вместе» |
| День рождения | Роза `#F4A5B9` | **Спец:** ежегодное, показывает возраст |
| Просто план | Кремовый `#D6CCB8` | Универсальная |

Категория = маленький залитый кружок 8-10px рядом с названием. Без иконки внутри.

## Идеи (без даты)

Отдельный «парковочный» блок внизу agenda — «то, что когда-нибудь хочется».

- Можно добавить без даты
- Drag-to-date (или tap → выбрать дату) → становится событием
- Видны обоим, кто угодно может «забрать» идею и поставить дату (интуитивный жест «давай я организую»)
- Не превращаются автоматически — остаются «вечнозелёными хотелками»

## Повторяющиеся события (особый класс)

- **Годовщина начала отношений** — заводится в Профиле → Общие даты, автоматически рендерится в календаре с подписью «1 год / 2 года / ...»
- **Дни рождения** — у обоих, автогенерируются ежегодно из Профиля → Общие даты
- **Пользовательские повторяющиеся** — например, «каждое 15 число — ужин дома». В MVP.

Подробнее об общих датах см. [profile.md](./profile.md#общие-даты).

## Cycle overlay (v0.2, её аккаунт)

В её календаре опционально:

- **Точка в углу дня** — фаза цикла (период, овуляция, неактивная фаза)
- **Только она видит** этот overlay
- Toggle в её настройках («показывать цикл на календаре»)
- Цветовой код: красная точка = период, зелёная = овуляция, бежевая = вне фаз. Очень тонко.

Партнёр видит свой календарь без cycle-маркеров. Никогда.

## Прошедшие события → Memory of the day

**Это ключевая интеграция.** Когда событие проходит (дата < сегодня):

1. Карточка слегка тускнеет, под ней появляется мягкий промпт «Как было?» (только если не отвечено)
2. Tap → можно добавить:
   - Фото (1-3)
   - Короткую заметку («это был лучший вечер недели»)
   - Mood-tag («тёплое», «смешно», «тяжело», «волшебно»)
3. Сохраняется как **«отмеченный момент»** — становится кандидатом на Memory of the day виджет в Доме

Так Memory не отдельный архив — это **ретроспективная маркировка прожитых событий**. Естественный поток: план → событие → воспоминание.

## Уведомления (per-event, per-partner)

- Дефолт: за 1 день и за 1 час до события (обе стороны)
- Per-partner override: «я хочу за 2 дня, она — за 1 час»
- Можно полностью отключить уведомление для конкретного события
- В MVP — только in-app badge при заходе. Web push — пост-MVP.

Подробно см. [04-privacy-and-notifications.md](../04-privacy-and-notifications.md#уведомления).

## Что НЕ в календаре (намеренно)

- **Не таск-менеджер.** Никаких todo, due-dates, чек-листов.
- **Без интеграции с внешними календарями** в MVP (Google/Apple) — это productivity-территория, не место для нашего ежедневника. Можно в v2 как опциональный read-only импорт.
- **Без timezone-логики** — мы в одном городе. Часовой пояс один.
- **Без приглашений / RSVP** — это не Eventbrite, в событии и так оба.
