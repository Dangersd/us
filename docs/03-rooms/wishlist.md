# Комната «Хотелки»

Не Amazon-витрина. **Доска желаний** — то, что мы хотим, любим, мечтаем.

**Ambient hue:** `#FFB4D1` розово-персиковое
**Эффекты:** glow вокруг сохранённых вещей, «звёздочки» при добавлении, pinboard-сетка

## Три списка

| Список | Что внутри | Кто видит |
|--------|------------|-----------|
| **Я хочу** | Мой персональный wishlist — что хотел бы получить | Я + партнёр |
| **Я люблю** | Что я уже люблю / нравится / у меня есть. Подсказки партнёру при выборе подарка | Я + партнёр |
| **Наше** | Что хотим вместе — путешествия, опыт, ужин, плед, вещь для дома | Оба, оба редактируют |

Доступ — через top-segmented control сверху комнаты: `Её • Мои • Наше • Я люблю` (порядок меняется зеркально для его/её аккаунта — у каждого первым список партнёра).

## Карточка хотелки

```
┌──────────────────────────────┐
│   [изображение]              │
│                              │
│   Свеча Diptyque             │
│   ● Дом · ~5000₽             │
│   «обожаю запах, нашла на    │
│    Озоне»                    │
│   [ссылка на товар]          │
└──────────────────────────────┘
```

**Поля:**

- Название (обязательно)
- Изображение (загрузка или URL — авто-парс OG-image при вставке ссылки)
- Категория цветом (одежда / парфюм / книги / дом / еда / опыт / путешествие / другое — без эмодзи, цветной кружок)
- Цена примерная (опционально)
- Ссылка (опционально)
- Заметка
- Приоритет «когда-нибудь / хочется / очень хочется» — три тихих градации, без чисел

## Виджет «Wishlist peek» на Доме

- 2 случайные карточки из «Хочу» партнёра + 1 из «Наше»
- Tap → переход в соответствующую секцию

См. [home.md](./home.md#5-wishlist-peek).

## Сортировка и поиск

- По умолчанию: новые сверху
- Опционально: сортировка по приоритету / категории / цене
- Поиск-строка простая (по названию + заметкам)
- Фильтр по категории — chip'ы под top-tabs

## Что НЕ в Хотелках

- **Surprise-механика** — рассматривали, отвергли как ненужное.
- **Трекинг подарков** — кто что подарил, история подарков. Не нужно.
- **Amazon-интеграция / автотрекинг цены / партнёрские ссылки.** Это **наша** доска, не магазин.
- **Shared cart / совместная покупка.** Если хотите купить вдвоём — это flow в реальной жизни, не в приложении.
- **Social-фичи** (publish list, sharing наружу) — приложение для двоих.

## Открытые вопросы

- Если «Я люблю» через 2-3 месяца не используется — схлопывать в «Хочу»? См. [07-open-questions.md](../07-open-questions.md).
