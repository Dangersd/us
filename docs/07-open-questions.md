# 07 — Открытые вопросы

Живой документ. Когда вопрос разрешается — переносим в соответствующий док и удаляем отсюда.

## Архитектурные

### AI Companion — layer или комната?

Когда дойдём до проектирования AI Companion, решить:
- **Floating layer** — компаньон присутствует поверх всех комнат (как Apple Spotlight, или плавающая иконка), доступен из любого места
- **5-я комната** — отдельное место с диалогом, как обычный chat-интерфейс
- **Гибрид** — soft nudges в виджетах + полноценный chat в отдельной комнате

Также: персонаж/тон, проактивный vs реактивный, какая модель, защита приватности при передаче LLM.

### Достаточно ли 3 предустановок personal hue?

Сейчас по дизайну — одна базовая для каждого гендера:
- Его: copper `#E8A87C`
- Её: rose `#F4A5B9`

Предлагаем 3 предустановки в рамках каждой роли:
- Его: copper / honey / earth
- Её: rose / blush / wine

Альтернатива — slider в пределах warm-палитры. Slider даёт больше контроля, но рискует развалить общий вайб.

**Решение:** в MVP — одна фиксированная за роль. Если захочется вариативности — добавим 3 пресета.

### Дополнительные функциональные гендер-асимметричные фичи помимо цикла?

В концепте только cycle является функциональным различием. Остальное — personal hue (визуал).

Возможные кандидаты на будущее:
- Pregnancy / postpartum (расширение cycle)
- Другие health-tracking (мужское здоровье — пока не очевиден use-case)
- Что-то ещё, что родится по жизни

Пока — нет.

## Продуктовые

### Если «Я люблю» через 2-3 месяца не используется — схлопывать в «Хочу»?

В Хотелках три списка: «Я хочу», «Я люблю», «Наше». «Я люблю» предполагается как подсказки партнёру при выборе подарков.

Если в реальном использовании окажется, что список пустой / редко обновляется — стоит проверить:
- Может, информация о «я люблю» лучше переходит через теги категорий внутри «Хочу» или через прямой разговор
- Если так — схлопнуть в «Хочу» и не плодить сущности

**Когда проверять:** через 2-3 месяца после v0.1.

### Memory of the day — что если за сегодня нет ни одного отмеченного момента?

В MVP виджет питается только из past events с фото+заметкой. Если за сегодня в истории ничего — виджет показывает случайный момент из всей истории или скрывается.

Альтернативы:
- Дать возможность добавить «свободное» воспоминание без привязки к событию (свайп вверх в виджете → «вспомнить момент»)
- Показывать «N лет назад в этот же день» из любых данных (mood, wishlist add)

**Решение:** наблюдать. Если виджет часто пустой — обсудить добавление свободного входа.

### «Этот день в нашей истории» для прошлых событий

Что если событие 6 месяцев назад на момент проведения не казалось важным, а в ретроспективе хочется отметить? Сейчас «Как было?» промпт появляется только сразу после события. Возможно стоит дать опцию вернуться к старому событию и добавить фото / mood-tag.

**Решение:** оставить как есть в MVP, добавить если будет запрос.

## Технические

### Realtime — нужен или нет?

Async-only философия не требует realtime. Но Supabase даёт его бесплатно. Опционально:
- Wishlist — партнёр добавил, ты видишь без refresh
- Календарь — то же
- Mood — обновление пары-glance виджета на Доме

Это nice-to-have, не критично. **Решение:** в MVP без realtime, добавить если будет дискомфорт.

### Particles / canvas — какая библиотека?

Floating particles на Доме и Настроении. Варианты:
- Чистый `<canvas>` (минимальный bundle)
- `tsparticles` (готовые конфиги, ~80kb)
- `react-particles` обёртка
- WebGL через `three.js` (overkill?)

**Решение:** начать с чистого canvas, минимальный код. Если захочется красивее — `tsparticles`.

### Service worker — самописный или Workbox?

Для PWA. Простой кейс — самописный SW. Сложный — `next-pwa` plugin (но он deprecated). Альтернатива — `@serwist/next` (наследник).

**Решение:** обсудить при имплементации PWA-части.

## Дизайн

### Iconography — кастом или библиотека?

Иконки навигации — точно кастомные (с метафорой). Остальные мелкие (плюс, закрыть, стрелки, дроп-даун) — из библиотеки (Phosphor / Iconoir) или тоже свои?

**Решение:** базовые UI-иконки из Phosphor (быстро), значимые иконки (Дом, Настроение, Календарь, Хотелки, Луна-профиль) — кастомные SVG в `src/components/icons/`.

### Loading state — пульсирующий blob везде?

В концепте: «не спиннер, а пульсирующий blob». Это красиво, но если делать одинаково везде — может стать монотонным. Возможно нужны вариации (mood-blob для mood, paper-fade для календаря, etc.).

**Решение:** базовый blob в MVP, вариации по комнатам — позже если захочется.
